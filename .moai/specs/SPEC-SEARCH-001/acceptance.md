## 1. 테스트 시나리오

### TC-001: 기본 키워드 검색

**Given** 183개의 녹취 파일이 인덱싱된 상태이고
**And** 검색 엔진이 초기화된 상태일 때
**When** 사용자가 "가스라이팅" 키워드로 검색을 요청하면
**Then** 해당 키워드가 포함된 모든 세그먼트가 반환되어야 하고
**And** 각 결과에 원본 세그먼트 ID가 포함되어야 하고
**And** 검색 소요 시간이 500ms 이내여야 한다

---

### TC-002: 한국어 형태소 분석 검색

**Given** 형태소 분석기가 활성화된 상태이고
**And** "위협했다"라는 텍스트가 포함된 세그먼트가 존재할 때
**When** 사용자가 "위협"으로 검색을 요청하면
**Then** "위협했다", "위협하고", "위협한" 등 활용형이 모두 검색되어야 하고
**And** 형태소 분석 결과에 기본형(lemma)이 포함되어야 한다

---

### TC-003: 화자 필터 적용

**Given** 검색 결과가 100개 존재하고
**And** 그 중 60개가 "신동식" 발언이고 40개가 "신기연" 발언일 때
**When** 사용자가 화자 필터를 "신동식"으로 설정하면
**Then** 60개의 결과만 반환되어야 하고
**And** 모든 결과의 speaker 필드가 "신동식"이어야 한다

---

### TC-004: 날짜 범위 필터

**Given** 2025년 6월부터 12월까지의 녹취 데이터가 존재할 때
**When** 사용자가 2025-07-01부터 2025-08-31까지 날짜 필터를 설정하면
**Then** 해당 기간 내의 결과만 반환되어야 하고
**And** 반환된 결과의 timestamp가 모두 지정 범위 내에 있어야 한다

---

### TC-005: 복합 조건 검색 (AND)

**Given** "가스라이팅"이 포함된 세그먼트가 50개 존재하고
**And** "부정"이 포함된 세그먼트가 30개 존재할 때
**When** 사용자가 "가스라이팅 AND 부정" 쿼리로 검색하면
**Then** 두 키워드가 모두 포함된 세그먼트만 반환되어야 하고
**And** 결과 수가 50개 미만이어야 한다

---

### TC-006: 복합 조건 검색 (OR)

**Given** "위협"이 포함된 세그먼트가 20개 존재하고
**And** "협박"이 포함된 세그먼트가 15개 존재할 때
**When** 사용자가 "위협 OR 협박" 쿼리로 검색하면
**Then** 두 키워드 중 하나 이상 포함된 세그먼트가 반환되어야 하고
**And** 중복 제거 후 결과가 반환되어야 한다

---

### TC-007: 정규표현식 검색

**Given** 검색 엔진이 정규표현식을 지원하고
**And** "가스라이팅", "가스등", "가스라이터" 텍스트가 존재할 때
**When** 사용자가 정규표현식 "가스.*" 패턴으로 검색하면
**Then** 패턴에 일치하는 모든 텍스트가 검색되어야 하고
**And** 각 결과에 일치 위치(start, end)가 포함되어야 한다

---

### TC-008: 유효하지 않은 정규표현식 처리

**Given** 검색 엔진이 초기화된 상태일 때
**When** 사용자가 유효하지 않은 정규표현식 "[invalid(" 로 검색하면
**Then** 적절한 오류 메시지가 반환되어야 하고
**And** 시스템이 예외 없이 안정적으로 동작해야 한다

---

### TC-009: 검색 결과 하이라이트

**Given** "그런 적 없어"라는 텍스트가 포함된 세그먼트가 존재할 때
**When** 사용자가 "그런 적 없어"로 검색하면
**Then** 결과의 highlighted_text 필드에 `<mark>그런 적 없어</mark>` 형식으로 표시되어야 하고
**And** 원본 텍스트는 변경되지 않아야 한다

---

### TC-010: 맥락 미리보기

**Given** 검색 결과가 반환되고
**And** context_chars가 100으로 설정되어 있을 때
**When** 검색 결과가 처리되면
**Then** 각 결과에 context_before와 context_after가 포함되어야 하고
**And** 각 맥락의 길이가 100자를 초과하지 않아야 한다

---

### TC-011: 페이지네이션

**Given** 검색 결과가 150개 존재하고
**And** 페이지 크기가 20으로 설정되어 있을 때
**When** 사용자가 3페이지를 요청하면
**Then** 41번째부터 60번째 결과가 반환되어야 하고
**And** total_pages가 8이어야 하고
**And** has_previous가 true이고 has_next가 true여야 한다

---

### TC-012: 관련도 정렬

**Given** "가스라이팅" 검색 결과가 50개 존재하고
**And** 각 결과의 관련도 점수가 다를 때
**When** 사용자가 관련도순 정렬을 요청하면
**Then** 관련도 점수가 높은 순서대로 정렬되어야 하고
**And** 첫 번째 결과의 score가 마지막 결과의 score보다 크거나 같아야 한다

---

### TC-013: 날짜순 정렬

**Given** 검색 결과가 반환된 상태일 때
**When** 사용자가 날짜순 내림차순 정렬을 요청하면
**Then** 가장 최근 날짜의 결과가 먼저 표시되어야 하고
**And** timestamp가 순차적으로 감소해야 한다

---

### TC-014: 중요도별 필터링

**Given** Evidence 데이터가 존재하고
**And** importance가 HIGH인 증거가 30개, MEDIUM이 50개, LOW가 20개일 때
**When** 사용자가 importance 필터를 ["HIGH", "MEDIUM"]으로 설정하면
**Then** 80개의 결과가 반환되어야 하고
**And** LOW 중요도의 결과가 포함되지 않아야 한다

---

### TC-015: 패턴 유형별 필터링

**Given** Evidence 데이터에 GASLIGHTING 40개, THREAT 30개, EMOTIONAL_MANIPULATION 25개가 존재할 때
**When** 사용자가 pattern_types 필터를 ["GASLIGHTING", "THREAT"]으로 설정하면
**Then** 70개의 결과가 반환되어야 하고
**And** EMOTIONAL_MANIPULATION 유형이 포함되지 않아야 한다

---

### TC-016: 근접 검색

**Given** "내가 그런 적 없어"라는 텍스트가 포함된 세그먼트가 존재할 때
**When** 사용자가 근접 검색 "내가 없어"~3 (3단어 이내)으로 검색하면
**Then** "내가"와 "없어"가 3단어 이내에 있는 결과가 반환되어야 한다

---

### TC-017: 와일드카드 검색

**Given** "가스라이팅", "가스등", "가스레인지" 텍스트가 존재할 때
**When** 사용자가 와일드카드 "가스*팅"으로 검색하면
**Then** "가스라이팅"만 반환되어야 한다

**When** 사용자가 와일드카드 "가스*"으로 검색하면
**Then** "가스라이팅", "가스등", "가스레인지" 모두 반환되어야 한다

---

### TC-018: 검색 인덱스 구축

**Given** 183개의 녹취 파일이 존재하고
**And** 각 파일이 30분 이상 분량일 때
**When** 인덱스 구축을 요청하면
**Then** 30초 이내에 구축이 완료되어야 하고
**And** IndexStats에 정확한 문서/세그먼트/토큰 수가 반영되어야 한다

---

### TC-019: 검색 시간 제한

**Given** 검색 시간 제한이 30초로 설정되어 있을 때
**When** 매우 복잡한 쿼리로 인해 30초를 초과하면
**Then** 검색이 자동으로 중단되어야 하고
**And** 적절한 타임아웃 오류 메시지가 반환되어야 한다

---

### TC-020: 검색 결과 내보내기

**Given** 검색 결과가 50개 존재할 때
**When** 사용자가 JSON 형식으로 내보내기를 요청하면
**Then** 유효한 JSON 파일이 생성되어야 하고
**And** 모든 결과가 포함되어야 하고
**And** UTF-8 인코딩으로 저장되어야 한다

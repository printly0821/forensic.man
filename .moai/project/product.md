# forensic.man

## 프로젝트 개요

**forensic.man**은 형사소송 증거자료로 사용될 녹취자료를 체계적으로 분석하는 Python CLI 도구입니다.

### 핵심 목적

가스라이팅 피해 증거를 시계열로 분석하여 법적 대응에 필요한 객관적 자료를 생성합니다.

---

## 대상 사용자

- 법적 분쟁에서 녹취 증거가 필요한 당사자
- 대량의 녹취 파일을 체계적으로 분석해야 하는 사용자
- 시계열 기반 증거 정리가 필요한 법률 관계자

---

## 핵심 기능

### 1. 대용량 파일 처리

- **스트리밍 처리**: 30분 이상 장시간 녹취 파일의 메모리 효율적 처리
- **청크 기반 분석**: 메모리 부하 없이 대용량 파일 순차 처리
- **배치 처리**: 183개 이상의 파일을 자동으로 일괄 분석

### 2. 시계열 분석

- **타임라인 생성**: 전체 녹취 기간(2025.06 ~ 2025.12)의 시계열 정리
- **화자 분리**: 신동식, 신기연 두 화자의 발언 구분 및 분류
- **패턴 인식**: 가스라이팅 패턴 및 반복 행위 탐지

### 3. 증거 정리

- **핵심 발언 추출**: 법적으로 의미 있는 발언 자동 하이라이트
- **맥락 보존**: 발언의 전후 맥락 포함한 증거 자료 생성
- **보고서 생성**: 소송용 증거 요약 문서 자동 생성

### 4. 검색 및 필터링

- **키워드 검색**: 특정 단어나 문구 포함 구간 빠른 검색
- **날짜별 필터**: 특정 기간 녹취 파일만 선별 분석
- **화자별 필터**: 특정 화자의 발언만 추출

---

## 사용 사례

### 사례 1: 전체 타임라인 분석

```bash
forensic analyze --input ./recordings/ --output ./analysis/
```

183개 녹취 파일을 분석하여 시계열 타임라인 생성

### 사례 2: 특정 패턴 검색

```bash
forensic search --pattern "특정 키워드" --input ./recordings/
```

특정 표현이나 패턴이 포함된 구간 검색

### 사례 3: 증거 보고서 생성

```bash
forensic report --input ./analysis/ --format legal
```

소송용 증거 요약 보고서 생성

---

## 기대 효과

1. **시간 절약**: 183개 파일 수동 분석 대비 90% 이상 시간 단축
2. **객관성 확보**: 자동화된 분석으로 주관적 해석 최소화
3. **증거력 강화**: 체계적인 시계열 정리로 법적 증거력 향상
4. **메모리 안정성**: 대용량 파일 처리 시 시스템 안정성 보장

---

## 제약 사항

- 녹취 파일은 텍스트 변환(STT) 완료 상태 필요
- 한국어 녹취 자료에 최적화
- Python 3.10 이상 필요
